FETCH-THEN-PASTE addendum 2026-06-20: subagents have LOCAL tools ONLY (no MCP, no web, no server ssh). A subagent gets MCP/web data only if the PARENT fetches it and pastes it into the prompt as plain text. WRONG: dispatch with 'Use emsu-operations read_server_file...' or 'Use web search...' (subagent hits 'use_mcp_tool not available', falls to raw ssh/curl, loops). RIGHT: parent calls the MCP/web itself, then dispatches 'Here is the file contents: <pasted>. Analyze for X.' Banned-dispatch-keyword self-check before every use_subagents: scan each prompt for 'use emsu-operations / use the MCP / use_mcp_tool / use web search / curl https / ssh wopr / ssh root@ / on the server run / check the server logs' — if present, the dispatch is doomed; fetch inline first.
